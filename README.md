This repository contains the full software stack for an autonomous foosball goalkeeper robot built as part of a mechatronics systems course at Tecnológico de Monterrey. The system mounts a stepper-driven carriage on precision linear rods, with a solenoid kicker, and is designed to eventually react to live ball tracking in real time.
Current state: The Arduino firmware (C++/PlatformIO) is fully modular and operational. Hardware is abstracted into purpose-built libraries — StepperAxis, JoystickAxis, Solenoid, LimitSwitch, RangeSensor, Ultrasonic, and ToF — each with clean, minimal APIs. All tunable parameters are centralized in constants.h and pins.h, keeping main.cpp free of magic numbers and easy to reconfigure without touching logic. Motion control uses AccelStepper with a two-pass limit-switch calibration sequence, coordinate-offset homing (to avoid mid-motion position resets), and a STOPPING deceleration state for smooth transitions. The joystick input path is threshold-gated to avoid redundant moveTo() calls that would disrupt AccelStepper's acceleration profile.
Coming next: A Python/OpenCV vision pipeline will track an orange golf ball via webcam using HSV color masking, Hough circle detection, and a Kalman filter ([x, y, radius, vx, vy, vr] state vector) to produce smooth, predictive position estimates. This will communicate with the Arduino over serial, replacing or augmenting the joystick input with camera-driven position commands — enabling fully autonomous goalkeeper behavior.
Why a GitHub repo? Beyond version control, the repo enforces a discipline the project depends on: separating concerns cleanly, keeping test code out of production firmware (test/ vs src/), and making it easy for multiple team members to work in parallel without stepping on each other. It also serves as living documentation — commit history captures every hardware bug found and fixed on real iron, which is as valuable as the code itself.
